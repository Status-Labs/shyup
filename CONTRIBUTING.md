# Contributing

Thanks for helping! Shyup stays small on purpose, so open an issue before a big change and we'll figure out if it fits.

- `just setup && just check` before you open a PR.
- Keep runtime dependencies at zero. Node built-ins only.
- Sign off your commits (`git commit -s`) to agree to the [Developer Certificate of Origin](https://developercertificate.org/).
- AI-assisted PRs are welcome. Say so in the description, and make sure you've read and run what you submit.
